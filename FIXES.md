# DoMedia Full Stack Developer Take-Home Test - Fixes

## Environment / Setup

I tested the project using:

- PHP 8.2.12
- XAMPP
- MariaDB 10.4.32
- Apache
- Google Chrome

### How to run

1. Install XAMPP or another environment with PHP and MySQL/MariaDB.
2. Start Apache and MySQL.
3. Import `app/schema.sql` into MySQL.
4. Check the database credentials in `app/db.php`.
5. Serve the `app` directory through Apache/XAMPP.
6. Open the application in the browser.
